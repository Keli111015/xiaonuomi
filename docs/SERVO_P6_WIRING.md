# 舵机改用P6（GPIO6）

当前主工程`sdk/apps/main/peripheral/bsp_servo.h`将舵机PWM由GPIO4改为GPIO6。摄像头VSYNC/CS继续使用GPIO4，不改变摄像头接线。

| 舵机线色 | 新接线 |
|---|---|
| 黄色，信号 | P6 / GPIO6 |
| 红色，供电 | 原有5V供电 |
| 棕色，地 | GND，与开发板及舵机电源共地 |

先关闭USB及其他电源，再把黄色信号线从P4移到丝印P6。不要把黄线接5V，也不要把舵机红线接3V3。相机供电仍为3V3。

## 软件行为

- 不上电自动转动，只有显式舵机命令才驱动。
- 保留75～105°调试范围，中心90°，驱动结束后释放PWM。
- 舵机使用LEDC timer0/channel0；相机转接板自带时钟，当前XCLK=-1；相机预留LEDC timer3/channel7与舵机不同。
- 原先“只要启用摄像头就禁用舵机”的保护改为与当前相机全部配置引脚逐一比较；只有真实GPIO冲突时拒绝初始化。
- GPIO6当前没有被应用其他外设占用；如额外连接自定义模块，仍需核对该引脚。

## 上板验收

2026-10-29软件验证：完整应用编译通过（0x316700字节），相机启用下P6通过冲突检查，P4/P21被拦截；相机关停时不误拦截P4。已写入0x20000应用分区并通过烧录哈希校验，启动查询显示舵机未启动、摄像头可用。尚未确认用户实际换线，也尚未进行实物转动及同时出图验收。

先烧录新固件，确认接线已移到P6，再执行：

```text
servo status
servo angle 90
servo angle 95
servo stop
```

观察实际转动及释放，再同时查看摄像头是否持续有效出图。串口回包只能确认命令执行，不能证明轴转到了指定角度。测试时预览工具和串口监视器不能同时占用同一COM口。

本次只解决舵机与相机的P4冲突；MPU6050默认SDA与相机DATA0仍共用GPIO8，没有一并解决。原overlay目录是历史快照，不是当前主工程，不能再覆盖到当前sdk。

# 舵机改用P6（GPIO6）

2026-10-31 按源码静态核对。本轮只更新文档，未编译、烧录或驱动硬件。项目状态见[当前交接](CURRENT_HANDOFF.md)。

当前主工程`sdk/apps/main/peripheral/bsp_servo.h`将舵机PWM由GPIO4改为GPIO6。摄像头VSYNC/CS继续使用GPIO4，不改变摄像头接线。

| 舵机线色 | 新接线 |
|---|---|
| 黄色，信号 | P6 / GPIO6 |
| 红色，供电 | 原有5V供电 |
| 棕色，地 | GND，与开发板及舵机电源共地 |

先关闭USB及其他电源，再把黄色信号线从P4移到丝印P6。不要把黄线接5V，也不要把舵机红线接3V3。相机供电仍为3V3。

## 软件行为

- 注册 CLI 时不启动 PWM；手动舵机命令和专注阶段自然结束提醒均可驱动。自动提醒的触发与取消规则见[专注结束摆头提醒](FOCUS_SERVO_REMINDER.md)。
- 保留75～105°调试范围，中心90°，驱动结束后释放PWM。
- `servo save` 将当前目标角保存为本次启动的 face 预设，`servo face` 转向该预设；不持久化，也不测量真实朝向。
- 舵机使用LEDC timer0/channel0；相机转接板自带时钟，当前XCLK=-1；相机预留LEDC timer3/channel7与舵机不同。
- 原先“只要启用摄像头就禁用舵机”的保护改为与当前相机全部配置引脚逐一比较；只有真实GPIO冲突时拒绝初始化。
- GPIO6当前没有被应用其他外设占用；如额外连接自定义模块，仍需核对该引脚。

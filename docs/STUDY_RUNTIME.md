# 学习规则与事件流

2026-10-31 按修复后的 SDK 源码静态整理，未编译或运行 C 状态机测试。生产实现位于 `sdk/apps/main/lj_components/morphcube/`，计时接入位于 `lj_components/pomodoro/`。早期 `firmware/` 副本不作为主应用规则来源。

## 事件和所有权

```text
云端 pomodoro 方法 → qm_pomodoro（唯一计时器）
                         ↓ 生命周期事件
Agent 聊天识别 ───────→ 学习事件队列 ←──── vision_service 姿态结果
                         ↓
                  morphcube_study_task
                         ↓
             mc_study 状态 / HP / 音效 / 耗尽结束本轮 / 结束摆头
```

学习状态由一个任务修改，其他模块通过队列传事件。时长使用 `esp_timer_get_time()/1000` 的单调毫秒时间，不依赖网络日历时间。番茄钟回调除提交学习事件外，还处理启动提示音检查、摄像头停止及每 10 秒的姿态请求；不能再概括为“只打印剩余时间”。

## HP 规则

| 事件 | 当前源码行为 |
| --- | --- |
| 重置一轮 | `mc_study_reset()` 设为 100 HP，内部以 0.1 HP 为单位保存 |
| 专注中聊天 | Agent 在一轮 ASR 结束后，将非番茄钟指令的聊天提交学习任务；每次有效事件扣 10 HP |
| 聊天去抖 | 两次有效扣血至少相隔 1000 毫秒；不是旧版的 60 秒 |
| 暂停专注 | 每完整一秒扣 0.2 HP；暂停倒计时不等于暂停扣血 |
| 坐姿提醒 | 达到累计门槛并通过 60 秒冷却后扣 5 HP；这是当前代码，不是早期“只提醒不扣血”规则 |
| 聊天或姿态耗尽 | 调用官方计时器 stop 结束本轮，再请求耗尽音效 |
| 暂停流血耗尽 | 同样 stop 结束本轮，再请求耗尽音效，不留在暂停状态 |
| 未耗尽的有效聊天/姿态扣血 | 播放受伤音效 |

`exhausted` 阻止重新激活学习状态，只有重置才清除。耗尽后计时器回到 IDLE，HP 保持 0；再次成功 start 从 IDLE 进入 FOCUS 时，学习任务重置为 100 HP 并清除耗尽及扣血记录。普通暂停/恢复和阶段切换不补满 HP。开场音乐只由成功进入新一轮的 STATE_CHANGED 事件安排，失败的 start 不安排音乐。上述重开链路尚未编译或实机验收。

专注期间非计时指令聊天会静音该轮云端回复，并触发本地反馈。这是产品规则启发式，不等于系统能可靠识别所有“开小差”。

耗尽后的本地 stop 成功时，学习任务通过现有 `ljyd_method_up("pomodoro", "stop", NULL)` 上报 `device/up`，参数沿用 `{"source":"local"}`，通知云端退出番茄模式。本地 IDLE 不代表云端对话状态已同步；上报成功日志仅表示发送接口成功，不代表云端确认或已切换模式。当前没有断网重试或云端业务确认，云端是否处理此上报仍需联调验证。不要用 `sendSpeakRequest` 播报文本代替状态同步。

耗尽音效设置的云端下行静音为临时状态：每次本地音效任务完成播放（包括编码或播放失败）后，在非活跃专注状态检查并解除，避免耗尽音效待播请求被合并覆盖时遗漏恢复；耗尽音效申请失败也执行解除。进入下一轮 LISTENING 时另作恢复检查，不依赖 final ASR 到达。活跃专注期间不通过这些恢复出口解除聊天静音。恢复日志为 `pomodoro inactive: restored agent downlink audio`。此修补尚未编译或实机验证。

Agent 下行播放准入与 Pomodoro 静音是独立状态。音频 operation 终态异常后保持其句柄，直到 qm_audio Control 成功释放；wait 返回 `-QM_ETIMEOUT` 时先检查 operation snapshot，避免把终态超时误判成等待超时。LISTENING 或 TTS_BEGIN 到达时记录准入恢复请求，旧操作释放成功后再开放下行。死亡音效播放期间另有 local-feedback mute，云端状态播报不会提前解除；结束后恢复当时的 Pomodoro 静音状态。诊断日志包含 `audio listening boundary`、`stream begin rejected` 及 `enqueue gated` 的 muted/accepting/operation 状态。本次未编译或实机验证。

## 坐姿采样与时长

自动请求周期为专注中的每 10 秒；相机不可用或对话忙时跳过。视觉服务将有效姿态映射并送入学习队列；正常 / UNKNOWN 会清空异常累计，暂停/停用也清空。

当前状态机使用以下参数：

- 相邻异常样本间隔超过 25 秒或时间倒退时清空累计。
- 相邻有效异常样本之间按实际经过毫秒累计，累计值封顶 15 秒。
- 累计门槛 15 秒，提醒冷却 60 秒。

这表示有效异常样本链覆盖至少 15 秒，不证明未采样期间持续异常。稳定的 10 秒采样下，第三个异常样本、首帧后约 20 秒达到门槛；推理时延和跳过会改变时序。这是静态推算，并非实测。详见[坐姿识别](POSE_RECOGNITION.md)。

## 专注结束

学习任务只在 FOCUS 阶段自然 PHASE_DONE 且非主动跳过时请求舵机提醒。暂停、停止、休息结束和 FINISHED 不额外触发摆头。动作细节见[专注结束摆头提醒](FOCUS_SERVO_REMINDER.md)。

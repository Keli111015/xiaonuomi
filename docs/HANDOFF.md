# MorphCube 团队交接说明

## 1. 已验证硬件

- 开发板：XJWB03 / ESP32-S3 revision 0.2
- PSRAM：8 MB
- Flash：16 MB，DIO，80 MHz
- 串口芯片：CH343
- 验证日期：2026-10-24

测试固件已在实板完成启动和串口交互验证。三个写入分区均通过 esptool 写入哈希校验。

官方完整语音工程已在 2026-10-25 接入 MorphCube 学习状态任务并完成整包编译；该整包尚未烧录到开发板。

## 2. 实板通过的流程

1. 上电进入 `idle`，25 分钟、100 HP。
2. `start` 进入 `focus`，倒计时递减。
3. 第一次 `distracted`：HP 100 → 90。
4. 60 秒内再次 `distracted`：返回 `ignored`，HP 不变。
5. `pause` 后等待，剩余时间不变；`resume` 后继续。
6. `stop` 保留本轮统计；`new` 恢复 25 分钟、100 HP。

## 3. 核心规则

- 单一任务拥有 `mc_study`，其他任务通过队列传事件，避免并发修改。
- 使用 `esp_timer_get_time()/1000` 的单调毫秒时间，不使用网络日历时间。
- 只有经过确认的分心事件才扣血；坐姿提醒永不扣血。
- 异常姿态需连续 15 秒；断帧超过 2 秒、正常或未知结果都会中断连续性。
- 重连或重复 `start` 不得恢复血条；只有明确的新一轮调用 `mc_study_reset()`。

## 4. 当前集成进度

第一阶段已完成：`integration/official-app/` 提供基于官方提交 `89020f5e0` 的适配源码和补丁。官方 Pomodoro 仍是唯一时钟，生命周期事件通过非阻塞队列交给 MorphCube 独立任务；云端 `pomodoro/distracted` 可用于模拟已确认的分心事件。完整工程编译结果为 0 错误，新增 MorphCube 文件无警告。

## 5. 尚未完成

按建议顺序继续：

1. 接摄像头真实推理结果，完成正常坐姿、歪斜、低头三类识别；不得重复使用旧帧冒充新结果。
2. 定义“开小差”的可靠来源，至少需要连续多帧或用户确认，避免误扣血。
3. 将 HP、剩余时间和状态映射到灯板；先查明灯板型号和引脚，禁止猜 GPIO。
4. 把口语练习场景和学习结束锐评放在云端智能体；板端只上报结构化统计。
5. 增加 NVS 持久化、断电恢复、看门狗、异常回滚和完整测试矩阵。

## 6. 安全与恢复

完整原厂闪存备份只保存在设备所有者本机，不上传 GitHub。团队成员烧录自己的开发板前，也应分别保存自己的完整备份。

官方根目录 `build.bat` 会执行擦除与烧录，不应用它代替普通的 `idf.py build`。

Windows 下应在纯英文、无空格路径构建，`IDF_TOOLS_PATH` 也应指向纯英文目录。官方随包 ESP-IDF 的配置脚本在中文用户目录中可能发生 GBK/UTF-8 解码错误；这属于工具链路径兼容问题，不应通过修改源码编码来掩盖。

## 7. 当前串口 JSON

示例：

```json
{"result":"ok","mode":"board_bench","phase":"focus","remaining_ms":1499499,"hp":90,"distractions":1,"camera":false,"cloud":false}
```

`camera:false` 和 `cloud:false` 是有意保留的事实标记，接入真实能力前不要改成 `true`。

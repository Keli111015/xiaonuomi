# 专注结束摆头提醒

本次范围：Agent/控制面板通过现有 pomodoro 方法启动设备番茄钟；设备专注阶段自然结束后自动提醒。无需 Agent 单独发送舵机角度，也未增加通用舵机工具。

## 行为
- 只处理 FOCUS 的 PHASE_DONE；短休息、长休息、暂停、停止、最终 FINISHED 不重复触发。
- SDK 新增 phase_skipped 字段，主动 skip 不触发动作。
- GPIO6 / P6，名义角度序列 80 → 100 → 80 → 100 → 90；每目标约 520ms，渐变 5°/40ms。
- 回中后自动关闭 PWM；这不等于断开舵机电源，也没有物理位置反馈。
- 使用现有后台运动任务；计时回调只投递学习事件，不阻塞等待动作。
- 舵机忙时拒绝新提醒并记录日志；servo stop 取消余下动作；手动 angle/face 覆盖提醒。
- 当前没有增加语音提醒、任意角度云端工具或自动面部追踪。

## 联调前
确认黄色信号线已从 P4 移到 P6、舵机供电和开发板共地，结构在 80..100° 内无阻挡。P4 留给摄像头。未确认接线前不要进行运动测试。

## 实机验收（待完成）
1. 启动设备番茄钟，专注自然结束：只摆头一次（左右两次），最后回中并释放 PWM。
2. 休息自然结束：不摆头；最后一轮专注结束同时产生 FINISHED 时不能重复摆头。
3. 暂停/恢复、手动停止、主动跳过：不产生结束提醒。
4. 动作中执行 servo stop：立即取消后续目标，保持 PWM 关闭。
5. 动作中手动 angle 90：取消余下摆头，只执行回中。
6. 连续两轮正常结束：每轮均能提醒；摄像头和语音保持可用。
7. Agent 启动后必须检查设备计时实际运行；仅云端口头回复开始计时并不代表设备收到 pomodoro/start。

当前代码编译验证与实机验收分开记录，未烧录不代表板上已有本功能。

# 专注结束摆头提醒

2026-11-01 当前规则：自然结束、语音/面板手动结束、血量扣完自动结束，均请求同一套舵机提醒。上电不自动转。

## 触发
- FOCUS 的 PHASE_DONE且非skip：自然结束提醒。
- 前一状态为FOCUS的STOPPED：不论是否exhausted均提醒；包含暂停中的专注被停止，以及聊天/坐姿扣血或暂停流血至0。
- FINISHED仅更新状态，不重复提醒。每次进入新的FOCUS清空本轮提醒标记；同轮已成功提交提醒后，不重复提交。
- 暂停/恢复本身、停止休息、空闲重复stop、skip不触发结束提醒。
- 旧语音板本地血量耗尽时，停止本机计时并通过加密板间桥接转发stop；动作板按角色拒绝再次转发，避免循环。

## 动作与约束
P6/GPIO6，50Hz，名义角度60→120→60→120→90，以90°为中心左右各30°（原±10°的3倍）。后台每40ms渐变约5°，每个目标预留720ms，整套约4.4秒完成并停止PWM。停止PWM不等于切断电源。
手动角度范围60..120。servo stop取消动作；手动angle/face覆盖动作。舵机忙或初始化失败时请求会被拒绝并记录，只有成功接受后本轮才标记为已提醒。没有机械位置反馈。

## 诊断
- servo status：查看提醒角度序列、60..120°命令范围、每目标720ms，以及已命令角度与PWM状态。
- servo probe：居中后对GPIO6输入电平做约200ms采样，随后关闭PWM；只确认引脚跳变，不能测量舵机供电、电流和轴位置。
- link status：查看双板角色、信道及最近发送/ACK序号。

## 验证与边界
主机测试覆盖70种事件/阶段/skip组合、血量耗尽STOPPED、重复STOPPED/FINISHED去重、新一轮复位、耗尽结束函数转发及失败分支；生产血量状态机测试通过。详见tools/tests/test_servo_host.py和test_board_bridge.py。
此前已在动作板做过5秒自然完成测试：倒计时到0后提交提醒，随后关闭PWM；GPIO6约200ms内检测到10次上升沿。测试后已恢复25分钟配置。这一历史测试不等于本次所有结束原因均已实机测过。
用户此前反馈舵机未实际转动，当前红接新板5V、棕接GND、黄接P6；尽管GPIO输出有跳变，供电、接触和舵机本体仍需排查。不能把软件ACK当作物理转动成功。

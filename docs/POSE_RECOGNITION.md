# 坐姿识别开发记录（2026-10-31）

基于 main c492bab1，保留既有扣血音效和舵机功能。

本次修复：校准不足3个有效稳定样本时上报UNKNOWN；完成后的基准不因重复add被意外清空；校准检查lean变化和非有限/零眼宽；cam calibrate重启采集，每张图仅自动计数一次；多人画面不选第一人判坐姿；摄像头仅在valid且calibrated时将姿态提交为正常或异常。

使用：固定相机，单人坐正并确保眼睛和双肩入镜。专注时自动采样校准。手动重校准执行一次 cam calibrate 90，然后用 cam pose 90 连续采样，观察cal_count=1/2/3；不要为每一帧重复发cam calibrate，因为它现在表示重启校准。角度按实际安装方向选择0/90/180/270，变化方向会清空基准。

校准仍为RAM状态；自动收集的端正样本不是人体工学标准，也未实现个人身份跟踪。未检出/多人/关键点不足按UNKNOWN处理，不将离开画面算走神。当前相对阈值是实验参数，未宣称准确率；坐姿异常不是不专注判定。本次未改动扣血通道。

离线测试：python tools/tests/test_pose_host.py --cxx <g++路径>。测试真实分类/校准函数的三帧计数、未校准UNKNOWN、完成后基准保持、低置信/缺失关键点拒绝、相对倾斜、重置、lean稳定性、非法校准输入；不覆盖模型真实关键点误差、多任务调度与实物相机。

实机待验收：同一位置坐正、向两侧倾斜、低头写字、短时遮挡、无人、两人、相机转向后重校准；分别保存有效率和误报次数。低头写字不能直接扣血。

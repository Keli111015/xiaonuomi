# MorphCube V1A早期结构原型

保留已有参数化CAD脚本与参数：`build_model.py`生成STEP/STL及几何信息，`preview.py`生成预览图；依赖见requirements.txt。请先阅读脚本并在独立目录运行，避免覆盖自己的生成物。

这是早期圆角立方体与旋转底座方案，尺寸约126×112×148mm，使用的硬件尺寸及内部空间含假设，尚未完成真实装配验收。它不是后来DeskPet绅士蛋/RevD模型，也不是隐藏升降三轮底盘的最终设计，不能直接据此确认可打印装配。

本目录只上传建模代码和参数，不附带大体积生成文件、第三方Blender模型或尚未验证的装配结论。

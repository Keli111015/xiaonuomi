# Application Playback

The current application uses `playback_init(void)` and `qm_audio_control` to submit PCM URI or file operations. The former decoder/source injection API described here is obsolete.

Maintained documentation is consolidated in [README_CN.md](README_CN.md) and the [API guide](resource_playback.md). Refer to `playback.h` for exact signatures. This documentation update was static only; no build or hardware test was performed.

qumi 调光库，将亮度值根据调光曲线映射到真实的亮度值，为了区分，下文中，属性亮度指代APP上设置的亮度值，物理亮度指代灯实际需要显示的亮度值，物理PWM占空比。
其中属性亮度范围：[0,10000] 物理亮度范围:[0,10000].
比如：
  - 线性调光下，属性亮度5000，会映射到5000的物理亮度。
  - 指数调光下，属性亮度5000，映射到1700左右的物理亮度，可以调节曲线参数来控制。

- 使用说明：
  - void pwm_alg_table_init(int curve_type, int lightness_min); 在系统初始化的时候调用，初始化曲线，lightness_min表示属性亮度为1%时，物理亮度值。
  - int pwm_alg_get_exp(int light_id, int lightness); 更改亮度时，调用此接口来获取物理亮度。注意：
    - 只有亮度PWM需要用此函数映射，色温PWM不需要。CCT中，色温PWM直接输出，亮度PWM需要调光曲线映射；CW中，先将亮度用此接口映射后，再根据色温来分配PWM
    - 渐变过程中，每次更改亮度，都需要调用此接口来确保输出曲线和设置的调光曲线一致
- 每次更改lightness_min 或者curve_type时，都需要再次调用pwm_alg_table_init来重新更改调光曲线
- 指数曲线，可以调节EXP_FACTOR 来控制曲线的弯曲度，数值越大，曲线前期变化越慢，目前使用的是2.43
- S曲线和对数曲线，由于用多项式计算太过耗时，影响启动，目前使用的是固定参数

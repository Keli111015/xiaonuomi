# 表情分类方案

| 一级分类 (Primary Category) | 表情项 (Expressions) |
| --- | --- |
| 基础面部状态 (Facial State) | 中性 (Neutral)、平静 (Calm) |
| 情绪情感 (Affect) | 开心 (Happy)、悲伤 (Sad)、愤怒 (Angry)、恐惧 (Fear)、惊讶 (Surprised)、焦虑 (Anxious)、兴奋 (Excited)、失望 (Disappointed)、厌恶 (Disgusted)、无聊或厌倦 (Bored) |
| 社会认知 (Social and Cognitive) | 期待 (Expectant)、好奇 (Curious)、困惑 (Confused)、犹豫 (Hesitant)、害羞 (Shy)、亲昵或撒娇 (Affectionate) |
| 身体状态 (Physical State) | 难受或身体不适 (Unwell) |
| 动作手势 (Gesture) | 点头 (Nod)、摇头 (Shake Head) |
| 未知 (Unknown) | 未识别、未提供或暂未归类的表情 (Unknown) |

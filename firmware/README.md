# 独立学习状态机与串口验证工程

此目录保留独立的 `mc_study.c/.h`、断言测试和 `board_bench/` 工程。完整产品开发入口是 `sdk/apps/main/`；本目录不包含生产应用的语音、云、摄像头或舵机集成。

## 文件职责

| 路径 | 用途 |
| --- | --- |
| `mc_study.c/.h` | 独立状态机副本，与 SDK 生产实现分别维护 |
| `test_mc_study.c` | C 断言测试，运行前需 C 编译器 |
| `board_bench/` | ESP-IDF 纯串口测试工程，不启用 Wi-Fi、云、相机、麦克风、电机或灯板 |

本轮文档整理开始时 `mc_study.c` 已有用户工作区修改，未改动。不能因为历史测试通过，就假定两份实现当前一致或可编译。

## 串口命令

仅适用于已烧录本目录验证固件的设备；不是完整 SDK 应用的同名 CLI。

| 命令 | 作用 |
| --- | --- |
| `status` | 查询状态 |
| `start` | 从 idle 开始一轮 25 分钟专注 |
| `pause` / `resume` | 暂停 / 恢复；当前源码包含暂停扣血调用 |
| `distracted` | 人工触发聊天/分心扣血事件，不是自动识别 |
| `stop` | 停止并保留统计 |
| `new` | 非运行时重置一轮、恢复 100 HP |

UART0 为 115200、8N1，命令以换行结束。当前具体规则需核对本目录实际状态机；生产应用规则另见[学习规则](../docs/STUDY_RUNTIME.md)。
